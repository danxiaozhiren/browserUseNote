# Browser Use Note

This repository is my working notebook for understanding Browser Use and practicing with browser-based AI agents.

It has two tracks:

- `learning`: concepts, mental models, project landscape, and reading notes.
- `practice`: small experiments that turn the ideas into runnable systems.

The first practice direction is `AI Info Radar`: a daily/weekly AI frontier briefing system that combines structured feeds, browser browsing, GitHub/Hugging Face signals, and human-readable summaries.
