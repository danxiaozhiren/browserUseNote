# Browser Use Note

This repository is my working notebook for understanding Browser Use and practicing with browser-based AI agents.

It has two tracks:

- `learning`: concepts, mental models, project landscape, and reading notes.
- `practice`: small experiments that turn the ideas into runnable systems.

`AI Info Radar` started here as a practice direction and has now been extracted
into its own repository: <https://github.com/danxiaozhiren/ai-info-radar>.
This repository keeps the Browser Use learning notes, mental models, and browser
agent experiments.
