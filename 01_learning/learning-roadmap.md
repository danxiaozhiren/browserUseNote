# Learning Roadmap

## Stage 1: Foundations

- Understand Playwright, WebDriver, CDP, and browser remote debugging.
- Compare DOM-based automation with screenshot-based Computer Use.
- Study why browser pages are unstable execution environments.

## Stage 2: Agent Patterns

- Observe-plan-act loops
- Tool calling and structured actions
- State machines and constrained workflows
- Retry, recovery, and verification
- Human approval and audit trails

## Stage 3: Product Directions

- Personal browser assistant
- AI information radar
- AI RPA for enterprise workflows
- Developer tools and browser debugging agents
- Cloud browser infrastructure

## Stage 4: Practice

- Build small browser automation scripts.
- Add AI extraction and summarization.
- Add source scoring and daily reports.
- Add browser interaction only where feeds or APIs are not enough.
