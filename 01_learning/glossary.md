# Glossary

## Browser Use

The general direction of using AI agents to operate browsers and web applications.

## CDP

Chrome DevTools Protocol. A low-level protocol for inspecting and controlling Chromium-based browsers.

## WebDriver

A browser automation standard widely used in traditional testing and enterprise automation.

## Playwright

A modern browser automation framework. It is commonly used as the execution layer for testing, scraping, and AI browser agents.

## Computer Use

A model capability where the AI observes the screen, then uses mouse and keyboard actions. It is more general than DOM-based browser automation, but usually slower and harder to make reliable.

## RPA

Robotic Process Automation. Enterprise automation for repetitive workflows, often across systems without clean APIs.

## MCP

Model Context Protocol. A protocol for exposing tools and data sources to AI applications in a structured way.

## Human-In-The-Loop

A design pattern where the user reviews, approves, or corrects the agent at important points.
