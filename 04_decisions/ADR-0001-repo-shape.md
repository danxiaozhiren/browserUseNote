# ADR-0001: Use A Learning And Practice Repository Shape

- Date: 2026-05-18
- Status: accepted
- Note: AI Info Radar was later extracted into its own repository. See ADR-0002.

## Context

This repository is intended to capture both my understanding of Browser Use and my practical experiments.

If it starts as a pure code repository, it may hide the conceptual work. If it starts as a pure note repository, it may not push ideas into practice.

## Decision

Use a dual-track structure:

- `01_learning` for mental models and study notes.
- `03_practice` for experiments and runnable projects.

Use `AI Info Radar` as the first practice project.

## Consequences

The repository can grow from notes into software without losing the thinking process behind it.
