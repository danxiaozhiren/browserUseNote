## Scoring Dimensions

| Dimension | Question |
| --- | --- |
| Importance | Is it from a key company, model, paper, or project? |
| Novelty | Is this actually new, or old wine in a new bottle? |
| Action value | Can it guide a decision or experiment? |
| Credibility | Is it first-hand or second-hand? |
| Relevance | Does it relate to Browser Use, agents, MCP, model capability, or AI tooling? |
| Momentum | Are stars, downloads, mentions, or rankings changing quickly? |
