# Browser Agent Labs

Small experiments for understanding Browser Use patterns.

## Experiment Ideas

- Playwright basics: open, click, type, extract.
- Compare DOM extraction with screenshot-based extraction.
- Build a constrained workflow with explicit verification.
- Test how pages break automation: popups, login expiry, infinite scroll.
- Try a human-in-the-loop final confirmation pattern.
