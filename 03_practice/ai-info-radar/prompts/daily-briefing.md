# Daily Briefing Prompt

You are creating a concise AI frontier briefing for someone focused on Browser Use, AI agents, MCP, open-source AI tooling, and model capability.

Use the input items to produce:

1. Top 5 most important items.
2. GitHub and open-source signals.
3. Model and product updates.
4. Papers and research.
5. Worth ignoring.

For each selected item, include:

- title
- one-sentence summary
- why it matters
- relevance tags
- source link
- confidence level

Do not include items only because they are popular. Prefer first-hand sources and items with clear action value.
